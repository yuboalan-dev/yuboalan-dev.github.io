# 設計與互動的細節

網站長什麼樣、為什麼這樣做。動到 `site.js`、`style.css`、`motion.js` 前先讀這份；使用者做過的決定在 [`decisions.md`](decisions.md)，規則總覽在 [`CLAUDE.md`](../CLAUDE.md)。

這份寫的是**現況**。改了設計就改這裡，不要往下疊「某月某日又改成…」；演變過程看 git 紀錄與 PR。

## 首頁

- 首頁：首屏是姓名（最大，`--fs-display`）→ 信念句（`--fs-xl`，句點是紅點）→ 求職句，右邊是本人照片裁成圓形（照片本身就是一個圓點）；接著「現在在做的事」、歷程路線圖（起點是十八歲公民權）。票數大字、簡介、關注領域不放首頁。決定的經過見 [`decisions.md`](decisions.md)。
- 字級：全站只用 `style.css` 第 0 段的 6 級——`--fs-xs` 13（日期、圖說）、`--fs-s` 15（次要文字、按鈕）、`--fs-m` 17（內文）、`--fs-l` 20（小標題）、`--fs-xl`（區塊標題、信念句）、`--fs-display`（姓名）。新增元件不要寫死 px。字重：姓名 900，其他標題 700。
- 紅色：只用在「現在位置」（路線圖最新一站、目前分頁、求職中）與句點；區塊標題前是深藍空心點，按鈕圓點深藍。依據是個人網站研究（rsms、Rauno：符號稀少才有力）。

## 圓點路線圖、經歷頁、媒體頁（v6，2026-11-02）

- 「圓點路線圖＋水滴」——經歷畫成捷運路線，圓點是站點也是水滴（實心＝現在、空心＝過去）；三個關注領域是三條路線色，也就是經歷頁的三段（student 學生自治藍、research 研究與教學金、transport 人本交通綠，`content.js` 的 `line`；經歷每筆自動用所屬組的顏色）；紅點只代表「最新一站」（路線圖最後一站，圖例 2026-11-02 由「現在位置」改名，因為議長等其他現職也還在進行）；首頁職涯路線圖依年份排列（`station`，站名用外人看得懂的簡稱，建中不上路線圖）、分段上色、每站連到經歷頁該筆；經歷每筆有組織圓章（`logo` 圖檔或 `mark` 簡稱），段名前有同色圓點、段名就是文字標籤（色弱也看得懂）；媒體頁一集一個點；字型：標題、姓名、站名、按鈕用昭源圓黑，內文用思源黑體（2026-11-02 改，長段落較穩重），按鈕膠囊形；CV PDF 維持黑體。使用者明確要求以圓點為 UI 核心、圓點寓意水滴。
- 連線一律用一顆顆圓點排成的點線（2026-11-02 使用者要求，取代長方形虛線），不用實線。

## 動畫

- 動畫（style.css 第 10 段）：站點水滴落下＋漣漪、路線分段畫出、捲動浮現（`data-reveal`）、集數點依序滴出、點擊水波；持續播放的只有路線圖「最新一站」的水波，以及路線圓點上的呼吸光（圓點不動，光點從第一段依序亮到最新一站，2026-11-02 使用者要求；10-2 段）。2026-11-02 依全站檢視拿掉其餘循環效果（虛線流動、圓點呼吸、照片漂浮、底紋漂移、簡介模糊淡入），使用者同意。全部以 `html.anim` 為前提，「減少動態效果」時不播、內容直接顯示；`tools/build.mjs` 存檔前會拿掉動畫狀態。

## 互動效果

- 互動效果（2026-11-02 使用者要求，`motion.js`）：只在訪客捲動、移動、點擊時才動——路線隨捲動一站一站畫出、首屏點陣被滑鼠推開並可點出漣漪（桌機）、路線站點滑過（手機點一下）出現預覽小卡、求職行輪播職缺類型、代表作與媒體數字捲到時累加、簡介關鍵字螢光筆、頁尾可甩動的掛繩識別證（寬螢幕）。2026-11-28 拿掉首頁卡通頭像的點陣互動（原第 8 段）。
- 首頁改版後還沒清掉的舊互動（首屏點陣、求職輪播、簡介螢光筆）：程式還在，要另開 PR 清（見改版路線圖 #30 第 1 期的待補）。
